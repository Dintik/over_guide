# Справочник по картам Overkings

Неофициальный справочник от игроков для игроков: где на картах находятся локации с боссами,
какие из них сильнее или слабее в своём регионе и какие эффекты накладывают монстры.

Сайт: https://dintik.github.io/over_guide/

- Цвет отметки — сила региона среди регионов карты (зелёный — слабее, жёлтый — средний, красный — сильнее).
- ▲ / ▼ — локация сильнее или слабее большинства локаций своего региона.
- Фильтр по эффектам: оглушение, замедление, превращение в волка, паника, ослепление, очарование,
  отбрасывание, атаки издалека, летающие монстры.
- Ссылка на локацию: `#<карта>/<локация>`, например `#sorian/zapovednik-ermoras`.

Сайт статический: чтобы открыть локально, запустите `python3 -m http.server` в корне и откройте http://localhost:8000.
